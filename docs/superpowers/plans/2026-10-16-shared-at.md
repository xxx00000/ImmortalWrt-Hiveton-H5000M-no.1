# H5000M shared AT implementation plan

> **For agentic workers:** Use subagent-driven-development for the independent daemon task and native execution for Web/package integration, followed by one fresh whole-change review.

**Goal:** Replace old MT5700M components with new Web sharing QModem's AT owner, validated before full firmware compilation.
**Architecture:** Extend pinned ubus-at-daemon with bounded per-port leases and serial/TCP ownership. Force QModem clients through it; adapt Python Web via ubus and line events. Keep QModem as dial controller.
**Tech Stack:** C/libubus, Python asyncio, POSIX shell, LuCI JS, GitHub Actions.
**Spec:** docs/superpowers/specs/2026-10-16-shared-at.md

## Global Constraints
- ImmortalWrt 25.12.2 source and existing pinned upstream revisions remain fixed.
- Work only on H5000M-notdream5700; no main changes or PR merge.
- No full firmware compile before all preflight checks pass.
- No device/hardware acceptance claim without actual hardware evidence.

## Review Focus
- Same physical serial device accessed through aliases must not create two owners.
- Client crash/disconnect or timeout during SMS prompt must safely end or quarantine session.
- Parallel polling must not consume command responses or SMS body.
- Existing retained device settings must not restore legacy/direct transport.
- A missing modem must not suppress WebSocket startup or expose unauthenticated commands.
