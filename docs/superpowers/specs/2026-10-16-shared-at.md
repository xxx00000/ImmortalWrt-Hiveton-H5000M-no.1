# H5000M shared AT specification

User approved scheme 1: extend QModem's pinned ubus-at-daemon; remove FAN789 luci-app-mt5700m, translations and mt5700m-transport; retain QModem, other plugins/drivers, fixed ImmortalWrt 25.12.2, feature branch H5000M-notdream5700, draft PR only. New inotdream Web auto-starts with per-device persisted WebSocket key and authenticated log clearing.

The menu is admin/modem/mt5700m, title 模组界面, ordered before QModem inside 调制解调器. Do not move the parent group. Open the real /5700/ Web, with versioned LuCI resources.

Only ubus-at-daemon opens AT serial/TCP endpoints. QModem CLI operations and Web operations acquire server-enforced per-port leases. One SMS operation (mode, prompt, payload, final response) is indivisible; abandoned or timed-out sessions must not leak responses into the next operation. No direct fallback on daemon failure. Web uses the selected QModem device's at_port; ambiguous/no modem is an explicit configuration error, never a guessed USB index. QModem remains the dial/reconnect controller. Dangerous competing autonomous Web schedule is disabled; dial/APN controls require shared QModem coordination.

Keep original frontend and WebSocket protocol where safe. URCs use qmodem.at.line, filter command responses and cross-port events, track loss/restart. Separate command result handling from unsolicited notifications.

Validation before full firmware compilation: daemon C transport/lease/PTY tests, client protocol/parallel/SMS/disconnect tests, no direct fallback audits, service startup without od, auth/log tests, actual pinned package integration/menu/asset checks. CI preflight gates full build. Build success is not hardware acceptance.
