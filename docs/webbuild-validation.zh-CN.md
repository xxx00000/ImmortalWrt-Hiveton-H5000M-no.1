## 独立审查

一次新的独立审查发现 3 项重要问题，均增加回归测试、先复现失败再修复：

1. 配置恢复后的再次重启保留无线设置，持久化首次启动标记并纳入备份。
2. 延迟的状态轮询不能覆盖成功完成状态。
3. Caddy 覆盖客户端身份头；匿名、已登录和 OIDC 请求使用独立限流预算。

审查建议另有两项轻微改进暂未纳入：默认构建 job 同样拥有 id-token:write（后端仍严格要求指定私人任务/run/提交）；较密集的代码排版可在后续单独整理。没有绕过身份校验或放开下载权限。

## 实施取舍

- 用 Node 内置 crypto 验证 RS256/JWKS，减少运行依赖；签名和声明均有负面测试。
- 使用已批准的同源 Docker 服务；Sites Workers 不满足本服务私有文件/流式存储需求。
- 权限检查使用明确的 collaborator role API，不依赖可能混淆 App 权限与用户角色的 repo.permissions 字段；只需原定 Metadata 只读权限。
- 通过连接器取得完整仓库快照并在独立本地分支开发；远端更新只针对用户指定分支。
